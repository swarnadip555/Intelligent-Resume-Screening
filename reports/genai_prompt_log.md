# GenAI Prompt Engineering Log & Code Explanations
## Intelligent Resume Screening & Job Matching System

This document provides a transparent audit trail of the GenAI prompt architecture, ethical guardrails, prompt templates, code implementation explanations, and sample prompt executions.

---

## 1. Prompt Engineering Architecture

### 1.1 Objective & Role Definition
The GenAI Assistant functions as an **Ethical HR Decision-Support Specialist**. Its purpose is to analyze a candidate's stated experience against a job description, identify evidenced strengths, flag missing criteria, and provide constructive upskilling suggestions.

### 1.2 Prompt Design Strategy
1. **System Prompt Constraint Enforcement:** Explicit boundaries prevent the model from:
   - Making autonomous hiring or rejection decisions.
   - Extrapolating or hallucinating unmentioned credentials.
   - Inferring or utilizing protected demographic traits (gender, race, age, location).
2. **Deterministic Information Extraction:** The prompt incorporates both extracted skills from the resume and explicit requirements from the target Job Description.
3. **Structured Markdown Output Schema:** Enforces standard sections for consistency across candidates.

## 2. System Prompt & Instruction Template

```markdown
You are an objective, ethical HR decision-support assistant designed to assist human recruiters in evaluating resume alignment with job requirements.

STRICT ETHICAL GUIDELINES:
1. Decision Support Only: Do NOT make a final hiring decision or declare candidate accepted/rejected.
2. Fact-Based: Base your evaluation strictly on the candidate's explicitly stated skills and experience. Do NOT extrapolate or hallucinate unmentioned credentials.
3. Fairness & Neutrality: Never infer or consider protected demographic traits (gender, age, ethnicity, disability, location, etc.).
4. Constructive Feedback: Highlight evidenced strengths, identify skill/experience gaps, and provide actionable upskilling advice.

Provide output in the following structured format:
### Candidate Alignment Summary
- **Target Role**: {target_role}
- **Experience Match**: {experience_summary}

### Evidenced Strengths & Matching Skills
{matching_skills_list}

### Missing or Non-Evidenced Requirements
{missing_requirements_list}

### Actionable Upskilling Recommendations
{recommendations_list}

### Responsible AI Disclaimer
This evaluation was generated by an automated decision-support system. It represents textual alignment only and must NOT be used as an automatic hiring filter. A human recruiter must review the full candidate profile in context.
```

## 3. Explanations of Generated Code

### 3.1 `src/data_loader.py`
- **Purpose:** Implements Task A data loading and exploration.
- **Key Functions:**
  - `load_and_clean_dataset()`: Reads `resumes.csv`, deduplicates by `candidate_id`, handles nulls, and engineers `text_length` and `word_count`.
  - `calculate_experience_statistics()`: Uses `np.mean()`, `np.median()`, `np.std()`, `np.percentile()` to compute robust statistical measures of experience.
  - `calculate_category_distribution()`: Measures category frequencies and relative percentages.
  - `analyze_skill_frequencies()`: Aggregates skills against a standard taxonomy.

### 3.2 `src/tokenizer_analysis.py`
- **Purpose:** Implements Task B tokenization experiments using Hugging Face Transformers.
- **Key Functions:**
  - `get_tokenizer()`: Loads DistilBERT's WordPiece tokenizer with automatic offline fallback.
  - `inspect_text_tokenization()`: Deconstructs text into subwords, vocabulary input IDs, and special tokens (`[CLS]=101`, `[SEP]=102`).
  - `analyze_technical_jargon()`: Evaluates tokenization behavior on technical terms (e.g., `PyTorch`, `CI/CD`, `MLOps`).
  - `add_token_count_feature()`: Vectorizes token counts across all resumes in Pandas.

### 3.3 `src/classifier.py`
- **Purpose:** Implements Task C supervised job category classification.
- **Key Functions:**
  - `build_pipeline()`: Constructs a scikit-learn `Pipeline` chaining `TfidfVectorizer(ngram_range=(1, 2))` and `RandomForestClassifier(n_estimators=100, class_weight='balanced')`. Ensures zero data leakage.
  - `train_and_evaluate_classifier()`: Executes stratified 80/20 train/test split, calculates precision/recall/F1, 5-fold cross-validation, confusion matrix, and extracts top feature importances.
  - `predict_category()`: Inference function returning class prediction and probability distributions.

### 3.4 `src/semantic_matcher.py`
- **Purpose:** Implements Task D semantic similarity matching using Sentence Transformers.
- **Key Functions:**
  - `get_embedder()`: Initializes `sentence-transformers/all-MiniLM-L6-v2`.
  - `match_resumes_to_job()`: Computes dense sentence embeddings and cosine similarities between candidate resumes and target job descriptions.
  - `compute_cross_category_matrix()`: Generates average similarity matrix across all 4 categories against all 4 benchmark job descriptions.
  - `analyze_keyword_vs_semantic()`: Highlights differences between literal keyword overlap and contextual semantic similarity.

### 3.5 `src/visualizer.py`
- **Purpose:** Implements Task E Matplotlib chart generation.
- **Key Charts Generated:**
  - `01_category_distribution.png`: Resume count per job category.
  - `02_experience_distribution.png`: Histogram with mean & median indicators.
  - `03_top_skills.png`: Horizontal bar chart of top skills.
  - `04_similarity_scores.png`: Ranked candidate similarity bar chart.
  - `05_confusion_matrix.png`: Confusion matrix heatmap for Random Forest.
  - `06_text_vs_tokens.png`: Character length vs. token count scatter plot.

### 3.6 `src/feedback_assistant.py`
- **Purpose:** Implements Section 6 GenAI Candidate Feedback Assistant.
- **Key Functions:**
  - `generate_feedback()`: Compares candidate resume with JD requirements, extracts matches, identifies skill gaps, formulates recommendations, and appends mandatory compliance disclaimers.
  - Persistent JSON logging: Writes every generation to `reports/genai_prompt_log.json` for governance and traceability.

- Candidate ID
- Input skills and experience
- Evidenced matches and missing criteria
